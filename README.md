# guide-index-pgsoft

## 项目简介

本项目是一个用于归档和发布多个独立 HTML 页面的仓库。所有页面均为静态资源，不依赖后端服务，可直接通过浏览器访问。适合用作页面集合、索引或轻量级文档展示。

## 目录结构

```
guide-index-pgsoft/
├── index.html          # 主入口页面
├── pages/              # 独立页面归档目录
│   ├── page-01.html
│   ├── page-02.html
│   └── ...
├── assets/             # 静态资源（CSS、JS、图片等）
│   ├── styles/
│   ├── scripts/
│   └── images/
└── README.md           # 本文件
```

- `index.html`：仓库主页，提供导航或页面列表。
- `pages/`：存放所有独立 HTML 页面文件，按需命名。
- `assets/`：存放公共样式、脚本及媒体资源，页面可引用。

## 页面归档说明

所有 HTML 页面均为独立、自包含的静态文件，未绑定特定域名或网站。页面内容以通用信息展示或工具功能为主，不涉及具体商业或推广用途。

- 页面文件名建议使用简短、有意义的英文或数字标识。
- 每个页面可独立维护和更新，互不干扰。
- 若需引用外部资源，请确保其稳定性或自行托管。

## 维护说明

- **添加新页面**：在 `pages/` 目录下新建 HTML 文件，并更新 `index.html` 中的链接（如有需要）。
- **修改现有页面**：直接编辑对应文件，注意保持资源引用路径正确。
- **删除页面**：移除对应文件，并清理 `index.html` 中的相关链接。
- **资源管理**：新增公共资源请放入 `assets/` 对应子目录，避免重复上传。

## 使用方式

1. 克隆或下载本仓库到本地。
2. 双击 `index.html` 或在浏览器中打开该文件即可查看页面列表。
3. 点击链接跳转至各独立页面。

也可将整个仓库部署至任意静态托管服务（如 GitHub Pages、Netlify 等），无需额外配置。

## 许可

本项目仅供学习和归档使用。页面内容如涉及第三方素材，请遵循其各自授权协议。
